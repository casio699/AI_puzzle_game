# Puzzle Challenge

A modular Python sliding puzzle game (3x3 to 6x6) with GUI, sound, statistics, and AI auto-solving (DFS, BFS, UCS, Greedy, A*). Designed for easy code reading, editing, and extensibility.

## Structure
- `main.py`: Entry point
- `config.py`: Settings, themes, constants
- `gui/`: GUI rendering, controls, themes
- `game/`: Board logic, AI, statistics
- `assets/`: Sounds, music, images
- `utils/`: Error handling

## Getting Started
1. Install requirements: `pip install -r requirements.txt`
2. Run: `python main.py`

## Features
- Dynamic grid (3x3–6x6)
- Customizable themes
- Music & sounds
- AI solvers & statistics
- Modular, well-documented code
